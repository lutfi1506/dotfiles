# 🚀 My Dotfiles

Personal configuration and environment setup for Fedora Linux.

## 🛠️ Quick Installation (Fresh OS)

1. **Clone this repo to Home directory:**
   ```bash
   git clone https://github.com/lutfi1506/dotfiles.git ~/dotfiles
   cd ~/dotfiles
   ```
2. **Jalankan installer:**
   ```bash
   chmod +x install.sh
   ./install.sh
   ```
